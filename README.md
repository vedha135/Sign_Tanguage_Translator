Sign Language Translator Using IoT

📌 Project Overview

The Sign Language Translator is an IoT-based project developed to help people with hearing and speech impairments communicate more easily. The system captures hand gestures using a USB camera and processes them using a Raspberry Pi. Recognized gestures are converted into words and displayed on an LCD screen. The system can also provide audio output and send SMS messages through a GSM module.

🎯 Objectives

- To recognize predefined hand gestures using a camera.
- To convert recognized gestures into meaningful words.
- To display translated words on an LCD screen.
- To provide audio output for recognized gestures.
- To send SMS messages using a GSM module.

⚙️ Hardware Requirements

💻 Software Requirements

- Raspberry Pi OS
- Python

- RPLCD

- Pygame

🔄 Working Principle

1. The USB camera captures the user's hand gestures.
2. OpenCV and MediaPipe process the captured hand movements.
3. The system identifies predefined gestures using Python logic.
4. The corresponding words are displayed on the LCD.
5. Audio output is generated through the speaker.
6. The GSM module can send SMS messages.
7. A push button is used to start or stop gesture capture.
